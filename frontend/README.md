## 🛠️ Built With

*   **React.js** - For the UI components and state management.
*   **Vite** - For fast development and bundling.
*   **HTML5 & CSS3** - For structure and responsive styling.
*   **JavaScript (ES6+)** - For logic and interactivity.
*   **FontAwesome** - For icons.

## 📂 Project Structure

```
├── src/
│   ├── components/  # React components for each section
│   ├── App.jsx      # Main application layout and state
│   ├── main.jsx     # React entry point
│   └── index.css    # Global stylesheet
├── public/          # Static assets like images
├── index.html       # Vite HTML template
└── package.json     # Project dependencies and scripts
```

## 🌟 Features

*   **React Component Architecture**: Clean and modular codebase.
*   **Responsive Design**: Fully responsive across desktops, tablets, and mobile devices.
*   **Dark/Light Mode**: Toggle implemented via React state.
*   **Smooth Scrolling**: Easy navigation across sections.

## 💻 Getting Started

To run this project locally:

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Biman2003/Portfolio.git
    ```
2.  **Install dependencies**
    ```bash
    cd Portfolio
    npm install
    ```
3.  **Run the development server**
    ```bash
    npm run dev
    ```
